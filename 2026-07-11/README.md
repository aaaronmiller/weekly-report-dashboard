# Weekly Dashboard Bundle

Open `index.html` in a browser or serve this directory with:

```bash
python3 -m http.server 8765
```

Files:
- `weekly-metrics.json` — dashboard data model
- `dad-report.md` — concise report
- `personal-report.md` — detailed source report
- `index.html` — static dashboard
