# Weekly Report Quality Review Checklist

## Phrases / Claims to Avoid

- "Full HTML report generated this week" -- only dashboard scaffold exists, no actual HTML report was produced
- "Pipeline ran successfully" -- the reporting pipeline was never executed
- "All deliverables complete" -- blockers exist (CASS CLI mismatch, variable typo) that prevent completion
- "Progress tracked in automated reports" -- output/reports directory is missing, no automation ran
- "Mentor feedback incorporated" -- only if mentor feedback is actually quoted or summarized in the report
- "Dashboard live and populated" -- scaffold exists but may not have real data
- "No blockers" or "On track with no issues" -- there are known blockers
- "All projects progressing equally" -- different items have different statuses; some are scaffold-only, some refined, some in pipeline
- "Search-tracker reports delivered" -- only if evidence exists that they were actually generated and reviewed
- "Career positioning summary included" -- only if actual career positioning text appears in the report

## Must-Include Facts

### Week Identity
- Subject line matching the dad report format
- Greetings opening
- Week ending date: May 31

### Completed / In-Progress Work
- Daily Radar scaffold status (scaffold complete or still in progress?)
- Agents infrastructure plan and pipelines
- Custom-skills repository work
- Switchboard sidebar work
- Model-scan refinement progress
- Claude-code-proxy profile routing
- Hermes plugins and skills
- Cron cleanup jobs
- Search-tracker reports status

### Strategic Overview
- A summary paragraph tying the above items into a coherent narrative
- Active project pipeline listing with status per item

### Progress This Week
- Per-project or per-area bullet points with concrete outcomes (not just "worked on X")
- Distinguish scaffold/planning from implementation/delivery

### Blockers Honestly Stated
- CASS CLI mismatch
- Variable typo blocking the pipeline
- No HTML report generated
- Output/reports directory missing

### Next Milestone
- What the next week's target is for each active project
- A clear priority order

### Mentor Feedback
- Actual mentor feedback content or "No mentor feedback this week" if none

### Career Positioning
- Explicit summary of how the week's work builds toward career goals

### Sign-Off
- "-A" closing signature per dad report format

## Structural Consistency Checks
- [ ] Report starts with Subject line
- [ ] Greetings paragraph present
- [ ] Strategic Overview before detailed breakdown
- [ ] Active Project Pipeline section lists all items
- [ ] Progress This Week matches pipeline items
- [ ] Blockers section present if any blocker exists
- [ ] Next Milestone section present
- [ ] Career Positioning section present
- [ ] Signed with -A
- [ ] No em dashes used anywhere in the report
- [ ] Every claim about a deliverable traces to specific evidence
- [ ] Scaffold-only items labeled as scaffold, not as completed deliveries
